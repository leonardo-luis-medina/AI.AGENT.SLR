# SolarQC Agent — Project Plan

## Project Overview
SolarQC Agent is a portfolio project that demonstrates
a genuine AI agent capable of reviewing fictional
Australian solar installation sales records.

The agent retrieves deal information, uses tools,
checks quality-control rules, consults policies,
and produces structured inspection results.

All customer and sales information is synthetic.

## Agent Requirements
The agent must:
1. Retrieve fictional solar sales records.
2. Select and call tools dynamically.
3. Apply deterministic QC checks.
4. Retrieve relevant company policies.
5. Explain findings using evidence.
6. Return PASS, FAIL, or NEEDS_HUMAN.
7. Record tool calls and inspection results.
8. Support both Gemini and Ollama.
9. Prevent uncontrolled or unsafe tool execution.
10. Be evaluated against known test cases.
